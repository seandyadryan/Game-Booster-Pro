Package: com.deploydulupulangnanti.gameboosterpro
App identity: Game Tools: Network & Cache

This source implements game shortcuts and device utilities, not performance boosting. Open game library lists installed apps identified as games and launches the selected package. Ordinary launching does not request Usage Access or overlay access, clear cache, change Do Not Disturb, or alter game settings.

The session/boost flow and the animation FPS demo have been removed. There is no game-FPS monitor, game-FPS overlay or graphics modification. The decorative rocket is retained only as navigation artwork. Screen refresh rate is labeled in Hz and is not game FPS.

This app's cache removes only Game Tools' temporary files after the user explicitly selects cleanup, showing measured sizes including zero. Other apps' private caches are not automatically cleared. Usage Access is optional for reading available cache sizes; external cleanup is manual in Android settings.

Network Latency measures TCP connection time to Cloudflare 1.1.1.1:443, not AI, game-server ping or network acceleration. App settings only opens Android settings; it does not close recent apps or stop other applications. The optional screen-Hz bar is separate from ordinary launching and requires disclosure and permissions.

Do Not Disturb is an independent consented toggle, reversible through the same control. It can silence alarms and media but does not reject calls. Battery information is displayed in the app dashboard, not as a game-performance measurement.
